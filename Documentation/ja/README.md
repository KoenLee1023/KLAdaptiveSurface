# KLAdaptiveSurface

> [English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)

`KLAdaptiveSurface` は、画像から得た色を読みやすい背景色に整えます。必要な場合も元の色相をできるだけ残します。画像の読み込み、画面状態の保持、ホストビューの表示方法は担当しません。

文字やコントロールの背後に置く色が暗すぎる、鮮やかすぎる、または濁って見える場合に使用できます。

# KLAdaptiveSurface

> [English](../../README.md) · [简体中文](../zh-Hans/README.md) · [繁體中文](../zh-Hant/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md)

`KLAdaptiveSurface`는 이미지에서 얻은 색을 읽기 쉬운 배경색으로 정리합니다. 필요한 경우에도 원래 색조를 가능한 한 유지합니다. 이미지 로드, 화면 상태 보관, 호스트 뷰의 표시 방식은 담당하지 않습니다.

문자와 컨트롤 뒤의 색이 너무 어둡거나 강하거나 탁해 보일 때 사용할 수 있습니다.
